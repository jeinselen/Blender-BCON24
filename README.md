# [Making Better Motion Branding](https://conference.blender.org/2024/presentations/3162/)

Procedural geometry nodes, creative UV mapping, dynamic materials, a bit of math, and a touch of web development; peek behind the curtain of how a new brand for a major corporation made their logo move. Building flexible iconographic setups and exploring brand motion for Launch by NTT DATA, John Einselen and Philip McCloskey present how Blender is a powerful tool for motion graphics, empowering not just design exploration and media production, but efficient creation of entire event packages.
